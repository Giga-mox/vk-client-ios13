# VK Classic Client for iOS 13+

Нативный клиент ВКонтакте для iOS 13+ на **Swift & UIKit** с обходом блокировок авторизации и автоматической облачной сборкой **.ipa** через GitHub Actions.

## Почему старые клиенты и моды перестали работать?
1. ВКонтакте отключил старые методы прямой авторизации по логину и паролю без 2FA (отказ от Direct Auth).
2. Старые Client ID были заблокированы или требуют обновленного протокола PKCE/VK ID.
3. В данном клиенте авторизация сделана через **WKWebView OAuth** (перехват официального токена в браузере с поддержкой всех видов 2FA/SMS) + **Прямой ввод Access Token**, что на 100% гарантирует вход.

## Как собрать IPA без Mac (за 5 минут):
1. Создайте бесплатный репозиторий на [GitHub](https://github.com/new).
2. Загрузите файлы этого проекта в репозиторий (через кнопку **Add file -> Upload files**).
3. Перейдите во вкладку **Actions** в вашем репозитории.
4. Выберите workflow **"Build iOS 13 VK Client IPA"** и нажмите **"Run workflow"**.
5. Через 3-4 минуты в завершенном запуске появится артефакт **VKClient-iOS13-ipa** — скачайте его.

## Как установить на iPhone через Windows:
1. Скачайте бесплатную программу **[Sideloadly](https://sideloadly.io/)** на компьютер с Windows.
2. Подключите iPhone к компьютеру кабелем USB.
3. Перетащите скачанный файл `VKClient-iOS13.ipa` в окно Sideloadly.
4. Укажите свой Apple ID (любой бесплатный) и нажмите **Start**.
5. На iPhone откройте **Настройки -> Основные -> Управление устройством** и нажмите **"Доверять"**.
